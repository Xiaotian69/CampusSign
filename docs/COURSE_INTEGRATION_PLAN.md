## 架构

采用同一窗口、独立课程工作进程。直接拼接两个主程序会造成 Tk 主循环、账号文件和任务状态冲突；完整重写不利于保留现有功能。独立进程适配来源课程引擎，签到模块不调用该引擎。

新增课程学习页面：选择现有账号、输入课程队列、选择浏览器、任务类型、答题方式、倍速及开始/结束时间；显示运行状态，支持停止。启动前显式点击运行，不自动登录或提交。AI 使用用户自己的密钥。

迁入课程导航及视频、音频、PPT、阅读、直播、讨论、作业和章节测验。来源签到实现不迁入。官方人脸验证由用户完成；不携带来源私人配置、Cookie、密钥、二进制扩展或人脸绕过实现。

每个任务的临时文件和进度使用隔离数据目录；敏感参数经标准输入传给工作进程，不放命令行。界面通过队列读取脱敏输出。停止只结束该任务进程树。缺失可选依赖时提示安装，基础签到仍能独立运行。
