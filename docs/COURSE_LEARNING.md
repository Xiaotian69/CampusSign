# 课程学习（本地集成版）

位置签到继续使用 CxSign 原有核心。侧边栏“课程学习”通过独立浏览器工作进程处理课程，基础签到不需要课程依赖。

## 启动

源码环境安装基础依赖后，另执行 `python -m pip install -r requirements-course.txt`，再运行 `python desktop_ui.py`。项目内已有 `.venv` 时，可双击根目录 `Start-CxSign.cmd`。

1. 在原账号管理入口添加自己的账号。
2. 打开“课程学习”，选择账号。默认 `qr` 使用官方扫码登录；`account` 使用保存的账号密码。学校账号若无法自动登录，在浏览器内手动完成。
3. 每行填写一门完整课程名，队列按顺序处理。选择 Edge 或 Chrome。驱动路径可留空，交由 Selenium Manager 查找/下载匹配驱动；也可手动选择本地驱动。
4. “课程”处理章节视频、音频、PPT、阅读和直播；讨论默认跳过，章节答题默认关闭。“作业”需选择 DeepSeek AI，并填写自己的 API Key 和模型名。
5. AI 使用 DeepSeek 接口，模型名称可自行修改。请求会把题目和选项发送给该服务。API Key 仅本次使用，不保存到设置。没有附带公共密钥或第三方免费题库服务。
6. 章节答题可选择 AI 或随机答题，并选择保存或提交；作业模式仅保存，最终提交请在官方页面核对。选择随机答题时来源引擎可能直接提交，请明确选择后再运行。
7. 点击“开始课程任务”才会启动浏览器。需要官方人脸验证时在官方页面完成。完成情况以学习通显示为准。

定时格式为 `YYYY-MM-DD HH:MM`，使用电脑本地时间；留空立即开始/不设结束时间。定时等待期间必须保持软件运行。停止按钮或关闭主窗口会结束本次课程进程及其浏览器子进程。

“同时运行课程数”默认为 1，可选择 2–3；并行时每门课程使用独立浏览器和数据目录，需要分别完成官方登录，是否允许同时学习由平台决定。保持唤醒选项用于运行期间防止系统休眠。

## 本地数据

课程设置保存在原有 `ui.local.json`，不含 API Key；运行进度和记录保存在 `course-data/`，该目录已忽略。每次运行目录隔离，课程实际完成状态仍由官方页面读取。请勿分享自己的数据目录。

## 功能边界与验收

本地版本已接入课程引擎，但离线测试不能证明平台当前所有页面均兼容。请先选自己创建或有权测试的一门课程，默认扫码、1 倍速、不刷题、跳过讨论，检查登录、课程识别、视频/文档、停止及进度；再单独验证作业和 AI。此阶段不自动执行真实签到或学习任务。

来源软件的签到实现、私人配置、二进制扩展、人脸绕过和多设备监控绕过未迁入。当前界面一次运行一个账号的课程队列。既有 SCUFE/Generic 版本差异保持不变。
