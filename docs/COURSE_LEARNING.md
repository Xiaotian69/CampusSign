# 课程学习（本地集成版）

位置签到继续使用 CxSign 原有核心。侧边栏“课程学习”通过独立浏览器工作进程处理课程，基础签到不需要课程依赖。

## 启动

源码环境安装基础依赖后，另执行 `python -m pip install -r requirements-course.txt`，再运行 `python desktop_ui.py`。项目内已有 `.venv` 时，可双击根目录 `Start-CxSign.cmd`。

1. 打开“课程学习”，点击“登录学习通”。默认使用官方扫码登录，不需要先保存账号或密码；浏览器默认自动选择（优先微软 Edge，失败再试谷歌 Chrome），驱动由 Selenium Manager 查找或联网下载。
2. 登录成功后，页面会读取“我学的课”列表。选择一门或多门课程（Ctrl 多选）；读取失败或找不到时，在手动输入框每行填写一门（可只填课程名中的一段）。
3. 点击“开始”处理所选课程。登录这一步只登录和读取列表，不会处理课程。点击“停止”或关闭主窗口会结束本次课程进程并关闭本次打开的浏览器，不影响你自己已打开的浏览器；停止后需要重新登录。

页面显示“当前设置”摘要和简短状态；“运行详情”展开后可查看日志，出错时会自动展开。默认值：扫码登录、1 倍速、单课程、不答题、跳过讨论、测验只保存不提交。

### 高级设置

“高级设置…”中可以修改：账号密码登录（账号来自“签到”页账号管理；学校账号无法自动填写时在浏览器内手动完成）、浏览器和驱动路径、任务类型、倍速、同时运行课程数、定时、保持唤醒，以及答题与 AI 相关选项。

- 章节测验可选“DeepSeek AI 答题”或“随机答题”。“测验答完后”选“只保存答案，不提交”时只点保存；选“自动提交（正式交卷）”时会正式提交且不可撤回。随机答题不会绕过“只保存”设置。
- “作业”模式需选择 DeepSeek AI，并且始终只保存，不自动提交；最终提交请在官方页面核对后自行完成。
- AI 使用 DeepSeek 接口，模型名称可自行修改，题目和选项会发送给该服务。API Key 仅本次运行使用，不保存到设置。没有附带公共密钥或第三方免费题库服务。
- 定时格式为 `YYYY-MM-DD HH:MM`，使用电脑本地时间；留空立即开始/不设结束时间。定时等待期间必须保持软件运行，到结束时间会关闭本次浏览器。
- “同时运行课程数”默认为 1。设为 2–3 时，“登录学习通”按钮不使用，每门课程使用独立浏览器和数据目录，需要分别完成官方登录；是否允许同时学习由平台决定。

需要官方人脸验证时在官方页面完成。完成情况以学习通显示为准：“处理到末尾”只表示程序走完了该课程的章节，不代表平台已记录完成。

## 本地数据

课程设置保存在原有 `ui.local.json`，不含 API Key；运行进度和记录保存在 `course-data/`，该目录已忽略。每次运行目录隔离，课程实际完成状态仍由官方页面读取。请勿分享自己的数据目录。

## 功能边界与验收

本地版本已接入课程引擎，但离线测试不能证明平台当前所有页面均兼容。请先选自己创建或有权测试的一门课程，默认扫码、1 倍速、不刷题、跳过讨论，检查登录、课程识别、视频/文档、停止及进度；再单独验证作业和 AI。

来源软件的签到实现、私人配置、二进制扩展、人脸绕过和多设备监控绕过未迁入。当前界面一次使用一个登录会话处理所选课程。既有 SCUFE/Generic 版本差异保持不变。
