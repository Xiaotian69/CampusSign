## 1. 第一次使用

1. 启动程序（`python desktop_ui.py`，或双击 `start_windows.vbs`）。
2. 首次启动会展示《用户须知》，点击「我已阅读并理解」进入主程序；点击「退出程序」则关闭。
3. 进入后默认停留在「首页」，左侧为导航栏（首页 / 签到 / 地点 / 学习资料 / 帮助 / 更新日志 / 关于）。

> 须知只在第一次确认后不再弹出；随时可在「关于」页重新查看。

## 2. 如何填写账号

1. 进入「签到」页；
2. 点击「添加 / 更新账号」；
3. 输入：
   - **账号**：学习通账号（一般是手机号）；
   - **密码**：学习通密码（界面会遮挡显示）；
   - **学校 ID**：仅学号登录才需要填写，手机号登录留空即可。
4. 点击「保存到本机」。

账号会保存在本机 `user.json`，支持添加多个账号；在列表中可用 Ctrl / Shift 多选。

## 3. 如何添加地点

1. 进入「地点」页；
2. 点击「添加 / 更新地点」；
3. 输入：
   - **完整地点名称**（与签到页面显示的地点一致，用于匹配）；
   - **百度经度**（BD-09，经度在前）；
   - **百度纬度**（BD-09，纬度在后）。
4. 点击「保存到本机」。

> SCUFE Edition 已内置「立信楼 / 南院 / 修德楼」等山财地点；Generic Edition 初始为空，需自行添加。
> 也可以使用「导入 / 导出地点」批量管理地点（JSON 文件）。

## 4. 如何选择签到地点

在「签到」页有两种模式：

- **固定位置**：在下方下拉框选择一个地点，每次签到都提交该地点的坐标，不依赖活动中的地点文字。
- **按指定地点匹配**：根据签到活动页面中的指定地点，自动匹配地点库中的地点。

## 5. 如何开始签到

1. 在「签到」页输入**完整课程名称**（需与学习通中的课程名一致）；
2. 选择账号（可多选）；
3. 选择位置模式与地点；
4. 点击：
   - **仅查询**：只读取活动和状态，**不提交签到**；
   - **查询并签到**：对进行中的位置签到执行一次。

## 6. 如何判断签到成功

- 结果列表中该账号的状态显示「**签到成功**」即表示已提交并复查通过；
- 已签到会显示「已签到，跳过」；
- 失败或异常会如实显示原因。

> 请以学习通内的实际状态为准。

## 7. 常见错误

| 提示 | 含义与处理 |
| --- | --- |
| 网络请求失败 / 读取失败 | 检查网络连接后重试 |
| 登录失败 | 核对账号密码，或先在学习通完成验证 |
| 没有找到此课程 | 核对课程名是否完整、是否已加入该课程 |
| 地点未匹配或匹配不唯一 | 核对地点名称与坐标，或在「地点」页补充 |
| 不在可签到范围内 | 固定坐标不在活动要求范围内，请确认地点 |

## 8. 如何反馈问题

请在 [GitHub Issues](https://github.com/Xiaotian69/CampusSign/issues) 提交问题，附上复现步骤与报错信息。**提交前务必遮挡账号、密码、Cookie、Token 等隐私信息。**

## 9. 如何更新

- **Release 版**：前往 GitHub Releases 下载新版本；
- **源码版**：`git pull` 拉取最新代码后重新安装依赖。
