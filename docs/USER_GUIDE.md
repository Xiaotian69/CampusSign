## 1. 第一次使用

1. 启动程序（`python desktop_ui.py`，或双击 `start_windows.vbs`）。
2. 首次启动会展示《用户须知》，点击「我已阅读并同意」进入主程序；点击「退出程序」则关闭。
3. 进入后默认停留在「首页」，左侧为导航栏（首页 / 签到 / 地点 / 学习资料 / 帮助 / 更新日志 / 关于）。

> 须知只在第一次确认后不再弹出；随时可在「关于」页重新查看。

## 2. 如何填写账号

1. 进入「签到」页；
2. 点击「添加 / 更新账号」；
3. 输入：
   - **账号**：学习通账号（一般是手机号）；
   - **密码**：学习通密码（界面会遮挡显示）；
   - **学校 ID**：仅学号登录才需要填写，手机号登录留空即可。
4. 点击「保存到本机」。

账号会保存在本机 `user.json`，支持添加多个账号；在列表中可用 Ctrl / Shift 多选。

## 3. 如何添加地点

### 地图选点（推荐，无需注册）

1. 进入「地点」页，点击「搜索添加地点」，停留在「地图选点」页；
2. 点击「打开百度地图」，在网页左上角搜索「学校名 + 楼名」，例如「山西财经大学 立信楼」；
3. 在左侧结果中点击要的那栋楼，地图上会出现它的红色标记；
4. 把鼠标放在红色标记上，滚动滚轮**放大到最大**（比例尺显示 10 米或 20 米）；
5. 拖动地图，让红色标记位于**整个浏览器窗口的正中间**；
6. 复制浏览器地址栏中的完整网址（带 `@` 的那一串），回到软件点击「从剪贴板粘贴并识别」；
7. 确认保存名称（会自动填入搜索词，可修改），点击「添加到地点库」。

> 为什么要放大并居中：网址里记录的是**地图中心点**，不是红色标记的位置。点开地点详情时百度会把地图下移给弹窗让位，在 14 级缩放下实测中心点偏了约 600 米；放大到最大并把标记拖到正中间后，误差可降到几米到二十几米。缩放级别低于 18 级的网址软件会直接拒绝。

> 原理：百度地图网页的网址里带有地图中心点坐标，软件在本机离线换算成百度经纬度，不需要账号，也不联网。
> 已经有经纬度时（如手机定位、其他地图），也可以直接粘贴「经度,纬度」，并在「坐标类型」里选百度 / 高德·腾讯 / 手机 GPS。

### 关键词搜索（需百度 AK）

1. 进入「地点」页，点击「搜索添加地点」，切换到「关键词搜索」页；
2. 第一次使用需填写**百度地图 AK**：点击「申请 AK」打开百度地图开放平台控制台，创建「服务端」类型应用，启用「地点检索」，IP 白名单填 `0.0.0.0/0`，复制 AK 填入（只保存在本机）；
3. 填写城市（可留空表示全国）和关键词，点击「搜索」；
4. 在结果中选中一个地点，按需修改「保存名称」，点击「添加到地点库」。可连续添加多个。

> 固定位置模式下保存名称可随意填写；「按指定地点匹配」模式需把名称改成与签到页面显示一致的完整地点名称。

### 手动添加

1. 进入「地点」页；
2. 点击「添加 / 更新地点」；
3. 输入：
   - **完整地点名称**（与签到页面显示的地点一致，用于匹配）；
   - **百度经度**（BD-09，经度在前）；
   - **百度纬度**（BD-09，纬度在后）。
4. 点击「保存到本机」。

> SCUFE Edition 已内置「立信楼 / 南院 / 修德楼」等山财地点；Generic Edition 初始为空，需自行添加。
> 也可以使用「导入 / 导出地点」批量管理地点（JSON 文件）。

## 4. 如何选择签到地点

在「签到」页有两种模式：

- **固定位置**：在下方下拉框选择一个地点，每次签到都提交该地点的坐标，不依赖活动中的地点文字。
- **按指定地点匹配**：根据签到活动页面中的指定地点，自动匹配地点库中的地点。

## 5. 如何开始签到

1. 在「签到」页选择账号（可多选），点击「**刷新课程**」读取这些账号已加入的课程；
2. 在课程下拉框中选择课程，输入关键字可筛选；也可以直接手动输入**完整课程名称**。选中课程后下方会提示哪些账号加入了这门课；
3. 选择位置模式与地点；
4. 点击：
   - **仅查询**：只读取活动和状态，**不提交签到**；
   - **查询并签到**：对进行中的位置签到执行一次。

## 6. 如何判断签到成功

- 结果列表中该账号的状态显示「**签到成功**」即表示已提交并复查通过；
- 已签到会显示「已签到，跳过」；
- 失败或异常会如实显示原因。

> 请以学习通内的实际状态为准。

## 7. 常见错误

| 提示 | 含义与处理 |
| --- | --- |
| 网络请求失败 / 读取失败 | 检查网络连接后重试 |
| 登录失败 | 核对账号密码，或先在学习通完成验证 |
| 没有找到此课程 | 核对课程名是否完整、是否已加入该课程 |
| 地点未匹配或匹配不唯一 | 核对地点名称与坐标，或在「地点」页补充 |
| 不在可签到范围内 | 固定坐标不在活动要求范围内，请确认地点 |

## 8. 如何反馈问题

请在 [GitHub Issues](https://github.com/Xiaotian69/CampusSign/issues) 提交问题，附上复现步骤与报错信息。**提交前务必遮挡账号、密码、Cookie、Token 等隐私信息。**

## 9. 如何更新

- **Release 版**：前往 GitHub Releases 下载新版本；
- **源码版**：`git pull` 拉取最新代码后重新安装依赖。

## 10. 课程学习（可选）

v1.2.0 起侧边栏新增「课程学习」，与签到相互独立：

1. 点「登录学习通」，在弹出的浏览器里扫码登录（不需要先保存账号密码）。
2. 等课程列表读出来后选择课程（Ctrl 多选）；读不出来时在下方手动输入课程名。
3. 点「开始」，状态行显示进度；点「停止」会关闭本次打开的浏览器。

默认只播放和翻页：不答题、跳过讨论、测验只保存不提交。倍速、定时、并行、答题与 AI 等选项在「高级设置…」中，完整说明见 [课程学习说明](COURSE_LEARNING.md)。完成情况以学习通页面为准。
