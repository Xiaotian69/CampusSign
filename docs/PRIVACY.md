# 隐私说明（Privacy）

本文说明 CxSign 如何处理你的数据。

## 账号信息保存在哪里

- 账号、密码、学校 ID 保存在本机 `user.json`（明文，非加密保险库）。
- 地点保存在本机 `locations.local.json`。
- 课程名、位置模式等偏好保存在本机 `ui.local.json`。
- 这些文件均通过 `.gitignore` 排除，不会进入公开仓库。

## 程序是否联网

- 程序只在「执行签到 / 仅查询」时，向学习通平台的相关接口发起请求。
- 打开窗口、浏览页面本身不发起任何签到请求。

## 是否上传到开发者服务器

- **不上传**。本项目没有开发者服务器，不存在把账号数据发送到作者服务器的行为。

## 凭据的用途

- 登录凭据仅用于在本机与学习通平台之间完成必要的请求（登录、读取课程与活动、提交签到）。

## 是否有遥测 / 统计 / 广告

- **没有**。本项目不包含任何遥测、行为统计、广告或第三方分析 SDK。

## 你应当注意的

- 账号以明文保存在本机，请勿在公共场所或他人设备上保存；
- 请勿分享包含本地配置的整个项目文件夹；
- 若怀疑账号、密码、Cookie 或 Token 已泄露，请立即到学习通修改密码并使会话失效。
