# 隐私说明（Privacy）

本文说明 CxSign 如何处理你的数据。

## 账号信息保存在哪里

- 账号、密码、学校 ID 保存在本机 `user.json`（明文，非加密保险库）。
- 地点保存在本机 `locations.local.json`。
- 课程名、课程列表缓存、位置模式、百度地图 AK 等偏好保存在本机 `ui.local.json`。
- 这些文件均通过 `.gitignore` 排除，不会进入公开仓库。

## 程序是否联网

- 程序只在「执行签到 / 仅查询 / 刷新课程」时，向学习通平台的相关接口发起请求；「刷新课程」只读取课程列表，不提交签到。
- 「搜索添加地点 → 关键词搜索」时，程序向百度地图开放平台发送搜索关键词、城市和你填写的 AK，不发送任何学习通账号信息；「地图选点」只在本机识别你粘贴的网址或坐标，不联网。
- 打开窗口、浏览页面本身不发起任何签到请求。

## 课程学习（可选功能）

- 课程学习在独立的浏览器窗口中打开学习通官方页面，登录（扫码或账号密码）在官方页面完成；扫码登录不使用本机保存的账号密码。
- 课程学习的非敏感设置保存在 `ui.local.json`；运行时生成的进度记录保存在程序目录下的 `course-data/`（按账号哈希和每次运行分隔，不含账号密码）。
- 账号密码只通过标准输入传给本机的课程子进程，不出现在命令行参数中；日志会隐藏账号、密码和 API Key。
- 只有你在高级设置中启用 DeepSeek AI 答题或讨论时，程序才会把题目、选项和你填写的 API Key 发送给 DeepSeek；API Key 不写入任何设置文件。

## 是否上传到开发者服务器

- **不上传**。本项目没有开发者服务器，不存在把账号数据发送到作者服务器的行为。

## 凭据的用途

- 登录凭据仅用于在本机与学习通平台之间完成必要的请求（登录、读取课程与活动、提交签到）。

## 是否有遥测 / 统计 / 广告

- **没有**。本项目不包含任何遥测、行为统计、广告或第三方分析 SDK。

## 你应当注意的

- 账号以明文保存在本机，请勿在公共场所或他人设备上保存；
- 请勿分享包含本地配置的整个项目文件夹；
- 若怀疑账号、密码、Cookie 或 Token 已泄露，请立即到学习通修改密码并使会话失效。
